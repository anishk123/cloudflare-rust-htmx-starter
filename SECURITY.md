# Security policy

Do not open public issues containing credentials, exploit details or private-environment data. For starter-level vulnerabilities, use GitHub private vulnerability reporting when enabled by the repository owner. Include the affected version or commit, impact, reproduction and any known mitigation without including live secrets.

Rotate an accidentally exposed secret immediately; deleting a Git commit is not secret rotation. See [Security architecture](docs/SECURITY.md), [Authentication](docs/AUTH.md), and [Secrets](docs/SECRETS.md) before adding sensitive data or reporting a design concern as a vulnerability.
